# Трекер ✨

Личное приложение для iPhone: задания с наградами в рублях, цели с фото и копилка.
Работает как веб-приложение (PWA): ставится на экран «Домой», открывается на весь экран,
работает без интернета. Все данные хранятся только на телефоне.

## Как это работает

- **Цели** — название, цена, фото, комментарий (ссылка, заметка или дата). Процент накопления считается сам.
  Набрала всю сумму → «Накоплено» → «Куплено!» с ценой покупки → цель уходит в архив.
  Купила дешевле — разница вернётся в кошелёк. Дороже — добирается из кошелька, а если там не хватает,
  приложение покажет, сколько нужно довнести.
- **Кошелёк** — нераспределённые деньги. Их можно разложить по целям, а деньги из целей переложить обратно.
- **Задания** — разовые (на конкретный день или без даты) и регулярные: каждый день, по дням недели,
  N раз в неделю, раз в N дней, раз в месяц. У любого задания можно включить «несколько раз в день» —
  оно засчитается, когда отмечены все разы.
- **Выполнила задание** → выбираешь, в какую цель положить награду → похвала с конфетти.
  Если цель переполнилась, лишнее уходит в кошелёк.
- **Бонус за серию** (выполнения подряд; для «N раз в неделю» — недели подряд): 4 → +5%, 7 → +10%, 14 → +15%, 21 и дальше → +20%.
- **Штраф за пропуск** — половина стоимости задания, списывается из кошелька. Если там пусто, появляется долг,
  и следующие награды сначала идут на него.
  - регулярное задание не сделано в свой день (или не отмечены все разы);
  - «N раз в неделю» — в конце недели за каждый недостающий раз;
  - разовое на конкретный день не сделано и не перенесено до полуночи — штраф, и задание переезжает на следующий день.
- **Категории** с эмодзи и цветом; создать можно прямо при создании задания. При удалении категории
  её задания переходят в «Без категории».
- **Итог дня** — утром карточка про вчерашний день, а когда сделано всё на сегодня — отдельная похвала.
- **Статистика** — неделя / месяц / всё время: выполнено, заработано, штрафы, задания и деньги по дням,
  разбивка по категориям, календарь активных дней.
- **Настройки** (шестерёнка на экране «Сегодня») — категории, свои фразы похвалы, резервная копия.

## Установка на iPhone

1. Один раз включить публикацию: в репозитории **Settings → Pages → Build and deployment → Source: GitHub Actions**.
   После этого каждый пуш в `main` сам собирает и выкладывает приложение
   (вкладка **Actions**, адрес вида `https://<логин>.github.io/tracker/`).
2. Открыть этот адрес в **Safari** на iPhone.
3. Нажать «Поделиться» → **«На экран „Домой“»**.

Обновления подтягиваются сами при следующем открытии приложения.

## Резервная копия

Данные живут в памяти Safari для этого приложения. Если удалить иконку с экрана «Домой», они пропадут.
Поэтому иногда делай копию: **Настройки → Сохранить копию → Сохранить в «Файлы»**.
Восстановить — там же, «Восстановить из копии».

## Для разработки

```bash
npm install
npm run dev      # локальный сервер
npm test         # тесты логики (деньги, серии, штрафы)
npm run build    # сборка в dist/
npm run icons    # перерисовать иконки (нужен Playwright)
```

Стек: React + TypeScript + Vite, `vite-plugin-pwa` для офлайна, IndexedDB (`idb-keyval`) для хранения.
Вся логика правил — в `src/logic/` и покрыта тестами в `src/logic/logic.test.ts`.
